A full-stack Java chess application I am building for C S 240, Advanced Software
Construction: game logic, a server with a REST API and WebSocket play, user authentication,
a database layer, and a terminal client, with unit and integration tests throughout. It is coursework rather
than research, and it is the project where I learned to design an interface between parts
of a system before writing either side. The repository is on my personal GitHub.
