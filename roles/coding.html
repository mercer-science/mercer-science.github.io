Coding

Software that left the prototype stage and got used.

I write code to solve research problems, and my best work is measured by whether anyone actually used it. The clearest example is a clinical imaging application I rebuilt that is now moving into use at a hospital, not a class project or a demo.

Shipped Software

  • A clinical imaging web app. I rebuilt a fragile, one-machine diffusion MRI pipeline into a web application that collects data from hospital network shares, repairs files, runs neural-network processing, and gives physicians a set of viewing and analysis tools. It processed seventy-six patients in about two and a half days and was handed to the hospital team that runs clinical software. Full write-up under Projects.
  • Clinical data extraction. I wrote C# scripts inside a treatment planning system that find and export the right data for each patient despite wildly inconsistent naming, asking a human only when they genuinely cannot resolve something.
  • A full-stack chess application. A Java client-server app built for BYU's advanced software construction course, with real network play.

AI Coding Agents

I build and study tools that let AI agents do real engineering work. In the Jensen Lab I am testing whether an AI agent can run a cryo-ET processing pipeline end to end while a human approves every step (see AI in Research). I used the same kind of agent to build the clinical app above. Under the Mercer Science organization I maintain open-source tooling for exactly this: paper-engine and github-ai-project-manager.

Foundations

I work in Python, R, C#, Java, and shell, and I am completing a computer science minor with a machine learning emphasis. I am comfortable with Git and GitHub on collaborative projects, with GPU workflows, and with messy real-world data formats like medical DICOM imaging.
